## Was KI hier heute kann

- **Code schreiben:** Von kleinen Skripten bis zu kompletten Web-Apps.
- **Erklären:** Fremden oder alten Code verständlich machen – Zeile für Zeile.
- **Fehler finden:** Fehlermeldungen deuten, Bugs aufspüren und beheben.
- **Testen & Dokumentieren:** Tests und Dokumentation erstellen, die sonst gern liegen bleiben.
- **Übersetzen:** Code von einer Programmiersprache in eine andere übertragen und Altsysteme modernisieren.

## So funktioniert's

<Level for="einsteiger">

Programmiersprachen sind auch Sprachen – mit sehr strengen Regeln. Sprachmodelle haben Milliarden Zeilen öffentlichen Code gelesen und gelernt, wie Programme aufgebaut sind. Der Vorteil gegenüber normalem Text: Code kann man ausführen und sofort sehen, ob er funktioniert.

</Level>

<Level for="anwender">

Ein **Coding-Agent** arbeitet in einer Schleife: Aufgabe verstehen → Dateien lesen → Plan machen → Code ändern → Tests laufen lassen → Fehler ansehen → korrigieren. Weil die KI das Ergebnis selbst überprüfen kann, wird sie viel zuverlässiger als bei reinen Textantworten.

Tipp: Gute Ergebnisse brauchen klare Aufgaben, Beispiele und automatische Tests – genau wie bei menschlichen Kolleg:innen.

</Level>

<Level for="profi">

Code ist eine ideale Domäne für **Reinforcement Learning mit verifizierbaren Belohnungen**: Unit-Tests, Compiler und Linter liefern objektives Feedback. Agent-Harnesses geben dem Modell Werkzeuge (Dateisystem, Shell, Suche, Browser) und verwalten Kontext über lange Sessions – etwa durch Zusammenfassen, Sub-Agenten und persistente Notizen.

Offene Probleme: Verständnis großer Codebasen jenseits des Kontextfensters, subtile Architekturentscheidungen, Sicherheit bei Tool-Zugriff (Prompt Injection) und die Frage, wie Menschen KI-generierten Code effizient reviewen.

</Level>

## Worauf du achten solltest

- KI-Code kann Sicherheitslücken enthalten – vor dem produktiven Einsatz prüfen lassen.
- Keine Passwörter oder Zugangsdaten in Prompts kopieren.
- Wer versteht, was der Code tut, kann KI viel besser steuern.
